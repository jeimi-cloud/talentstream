# TalentStream

**Tu proceso de selección, en un solo flujo.**

TalentStream es un emprendimiento que ofrece una plataforma de software para centralizar el reclutamiento y la selección de personal, dirigida a pymes colombianas y agencias de selección. La inteligencia artificial apoya la lectura de hojas de vida; las decisiones las toman personas.

🔗 **Página publicada:** https://jeimi-cloud.github.io/talentstream/

---

## Proyecto académico

- **Asignatura:** Electiva 1 — Herramientas de IA para la Transformación Digital
- **Institución:** Fundación Universitaria Cafam (UNICAFAM)

## Secciones de la página

| Sección | Qué incluye |
|---|---|
| Inicio | Portada animada con panel interactivo y eslogan |
| Nosotros | Problema, propuesta de valor, diferenciadores y comparador antes/después |
| Servicios | 6 servicios con ilustración que cambia al seleccionarlos |
| Demo de IA | Simulación de lectura asistida de una hoja de vida |
| Cómo funciona | 4 pasos interactivos y galería en carrusel |
| Calculadora | Estimación ilustrativa del tiempo ahorrado |
| Planes | Básico, Pro y Empresa, con precio mensual o anual |
| Preguntas frecuentes | Acordeón de preguntas |
| Contacto | Formulario con validación |

## Tecnologías
